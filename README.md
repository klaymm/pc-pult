# pc-pult

![Release](https://img.shields.io/github/v/release/klaymm/pc-pult) ![License](https://img.shields.io/github/license/klaymm/pc-pult) ![Go](https://img.shields.io/github/go-mod/go-version/klaymm/pc-pult?filename=router/go.mod) ![Platform](https://img.shields.io/badge/platform-Keenetic%20%7C%20Windows-blue)

Управление компьютером с Windows через бота в Telegram. Бот работает на роутере Keenetic или Netcraze, поэтому отвечает и тогда, когда компьютер выключен: роутер включает его по сети.

## Возможности

- **Питание** - включение по сети (Wake-on-LAN), выключение, перезагрузка, сон, гибернация, блокировка, выход из системы, таймер
- **Состояние** - загрузка и температура процессора и видеокарты NVIDIA, память, диски, сеть, время работы
- **Скриншоты** - всех экранов или одного, оригинал можно получить файлом
- **Звук и музыка** - громкость, пауза, переключение треков
- **Сообщения** - окно с текстом на экране, чтение текста вслух, текст в буфер обмена
- **Программы** - запуск из списка, поиск процесса и его завершение
- **Файлы** - просмотр папок, скачивание, загрузка на компьютер, удаление
- **AnyDesk** - ID, управление службой и пароль для доступа
- **Уведомления** - вход и выход из Windows, блокировка, перегрев, мало места на диске
- **Пользователи** - владелец приглашает людей ссылкой и выбирает права: гость, пользователь или админ; действия записываются в журнал

## Установка

Нужен роутер Keenetic или Netcraze с Entware (менеджер пакетов для роутера), компьютер с 64-разрядной Windows 10 или 11 и бот, созданный у @BotFather.

1. Зайдите на роутер по SSH, наберите `exec sh` и выполните:

```
opkg update && opkg install ca-certificates wget-ssl && wget -qO- https://raw.githubusercontent.com/klaymm/pc-pult/main/install.sh | sh
```

2. Мастер спросит токен бота, даст ссылку, по которой вы станете владельцем, и напечатает команду для компьютера.
3. Вставьте эту команду в PowerShell на компьютере. Она сама запросит права администратора, поставит службу и свяжется с роутером.

### Если Telegram заблокирован

Мастер предложит три способа выхода в Telegram: напрямую, через свой Cloudflare Worker (бесплатная пересылка запросов, мастер покажет её код) или через прокси. Если Worker у вас уже есть, мастер просто спросит его адрес. Код нового Worker проверяет секретную часть адреса, её создаёт мастер, поэтому посторонние не смогут пользоваться вашим Worker. Токен бота проходит через ваш аккаунт Cloudflare.

## Частые проблемы

- **Компьютер не включается из бота.** Включение по сети работает только по кабелю. В BIOS должен быть включён Wake on LAN.
- **Бот не отвечает.** Посмотрите журнал на роутере: `tail -f /opt/var/log/pc-pult.log`. Если в нём ошибки связи с Telegram, укажите адрес Worker в поле `tg_api` или адрес прокси в поле `tg_proxy` файла `/opt/etc/pc-pult/config.json` и перезапустите службу: `/opt/etc/init.d/S99pc-pult restart`.
- **Компьютер показан выключенным, хотя он включён.** Журнал службы лежит в `C:\ProgramData\PcPult\logs\service.log`. Если связи с роутером нет, подключите компьютер заново: `/opt/sbin/pc-pult-router -pair` на роутере и новая команда на компьютере.
- **Нет температуры процессора.** Служба не смогла открыть датчики, остальное работает.
- **Windows или антивирус задаёт вопрос про службу.** Программа не подписана цифровой подписью.

## Обновление и удаление

Обновление: та же команда на роутере и на компьютере, настройки сохраняются. Чтобы подключить другой компьютер, выполните на роутере `/opt/sbin/pc-pult-router -pair`.

Удаление с роутера:

```
wget -qO- https://raw.githubusercontent.com/klaymm/pc-pult/main/install.sh | sh -s remove
```

С компьютера программу удаляет команда установки с параметром `-Remove` вместо `-Router` и `-Code`.

## Чего не умеет

Работает только с роутерами Keenetic и Netcraze с Entware. Проверено на Netcraze с процессором aarch64 и Windows 11, версии для других процессоров роутеров собираются, но на устройствах не пробовались.
